PROJECT 01 / 量化研究

交易算法智能路由

PAIRWISE COMPARISON / DIRECTION / MAGNITUDE

同一只股票，在不同状态下可能适合不同的交易算法。研究围绕“何时应从默认方案切换到另一方案”展开，将问题拆解为数据核对、相对标签构建、方向与幅度建模，以及时间样本外验证。

01

问题与参与内容

相比单独预测某一算法的收益，路由决策更关心一个相对问题：在同一对象、同一目标期上，方案A是否优于默认方案B？即使两个方案都盈利，切换到相对较差的方案也可能损失增量收益。

因此，研究以固定基准方案为参照，将建模目标与实际选择问题对齐，而不是仅根据某个算法的绝对收益判断是否切换。

我的参与包括数据处理与一致性检查、配对标签构建、模型训练和走步评估，以及日常数据处理、训练与预测流程的自动化搭建。

02

先配对，再构造差值

以“对象、特征时点、目标时点”为键，对两个方案的已实现结果进行一对一配对。标签来自真实结果的差值，而不是先训练两个绝对收益模型、再把预测结果相减。

SAME OBJECT / SAME PERIOD / SAME RETURN BASIS

delta = return_A - return_B

delta大于0，表示A优于B；小于0，表示B优于A；等于0，表示两方案在该评价口径下持平。

  • 严格配对。对象、目标时间、收益计算口径和单位必须一致，不能跨对象或跨期直接相减。
  • 缺失不等于零。只有两侧结果均有效时才构造标签；已确认的真实零结果可以保留，未知或异常结果不能填成零。
  • 固定方向。始终使用A减B，保证标签符号的含义一致，避免训练、评估和路由阶段混淆。

这一设计有助于控制同一场景中的共同影响，让模型更直接地学习方案间差异，但配对本身并不等于消除了全部噪声，也不自动构成因果识别。

03

方向与差异强度分开学习

同一个差值可以产生两个不同的学习目标：一是“哪一侧更好”，二是“两者差异有多大”。分类与回归分别处理，避免把胜率与收益幅度混为一谈。

DIRECTION / 方向

P

A胜过B的概率

使用LightGBM二分类模型，预测给定当前特征时，A的结果严格优于B的概率。

全局P标签在有效配对中定义为：delta大于0取1；delta小于或等于0取0。缺失结果不参与标签构造。

MAGNITUDE / 差异强度

Q

选择这件事有多重要

以abs(delta)为标签，使用稳健回归学习差异强度，用于识别差异较大的对象。

高Q不代表A一定更好，既可能大赢，也可能大输；幅度评分也不应未经校准就解释为精确的预期收益。

特征围绕比较问题构造，包括两个方案各自的历史状态、双方特征之差、配对历史差值与胜率，以及共同的市场环境。历史统计只使用决策时已经可获得的信息。

模型分数可以用于候选排序和分层，但P与Q的简单乘积并不天然等于预期增量收益。是否切换，仍需要结合成本、资格约束和样本外验证结果判断。

04

把验证放在时间之外

采用按日期推进的走步样本外预测（OOF），而不是把同一时间段中的样本随机打散。每个目标日都只使用此前可获得的数据训练和选择模型。

  1. 01 / ALIGN对齐历史数据

    核对时间、对象与标签口径。

  2. 02 / TRAIN仅用过去训练

    在历史窗口内训练与验证。

  3. 03 / PREDICT预测下一目标日

    保留真实的样本外输出。

  4. 04 / COMPARE与默认方案比较

    评估增量与风险，而非只看拟合。

  • 时间与口径一致。将特征可用时间、标签所属期间和模型训练截止时间明确分开，检查未来信息泄露。
  • 参数敏感性。比较不同评估窗口、候选比例和筛选条件，观察结论是否依赖单一设置。
  • 极端值检验。比较原始结果与多档缩尾结果，判断平均增量是否主要来自少数异常对象或日期。
  • 按日评估。结合正增量日占比、HAC统计和区块Bootstrap，关注时间相关性及有限样本的不确定性。
  • 流程一致性。核对历史路由记录与回测决策，避免研究逻辑与实际预测流程不一致。
05

工程与研究思考

除了模型本身，还需要将数据校验、训练、预测和日志记录串成可重复运行的流程。结果异常时，先核对数据完整性和口径，再判断是否为模型问题，不能把所有异常都解释为市场变化。

这段研究让我更重视三个区别：排序能力不等于概率校准，方向正确不等于收益一定更高，回测表现也不等于未来保证。研究的价值不仅在于一个模型分数，还在于完整的数据边界、验证过程和可复查的决策记录。
